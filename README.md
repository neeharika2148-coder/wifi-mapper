# 📶 WiFi Mapper

## 🚀 About the Project

WiFi Mapper is a Python-based project designed to visualize and explore WiFi-related data in a simple and user-friendly way.

The project combines WiFi data generation, data processing, and mapping functionality to provide an easy way to understand WiFi information.

## ✨ Features

- 📍 WiFi data mapping
- 🗺️ Interactive visualization
- 📊 WiFi data exploration
- 📁 CSV-based WiFi dataset
- 🐍 Python-based implementation
- ⚡ Simple and lightweight project
- 🎯 Easy to understand and extend

## 📂 Project Structure

- `app.py` – Main application
- `mapper.py` – Mapping and processing functionality
- `generate_data.py` – WiFi data generation
- `wifi_data.csv` – WiFi dataset
- `requirements.txt` – Project dependencies
- `README.md` – Project documentation

## 🎯 Project Objective

The main objective of WiFi Mapper is to make WiFi-related data easier to visualize and understand through a simple Python application.

## 🔮 Future Enhancements

- 📡 Real-time WiFi detection
- 📍 Live WiFi mapping
- 📊 Signal-strength visualization
- 🔎 WiFi search and filtering
- 🗺️ Advanced interactive maps
- 📱 Improved user interface
